# 关于这一页

欢迎来到 **Yolim Blog**。

这里是一间慢慢整理出来的小房间：我会记录近来的生活与随想，分享真正觉得有用的知识，也会把求学、项目和喜欢的音乐留在这里。

## 我正在做什么

目前就读于上海交通大学海洋科学专业，参与冰冻圈、水资源和蓝冰冰芯相关研究。比起快速得到答案，我更希望每一步分析都能被解释、核验，并在之后继续使用。
